# sdg-tech-impact-tagger

Label texts with an LLM behind any OpenAI-compatible endpoint: sustainable
development goals (SDGs), advanced digital technologies, the impact of a
technology on a goal, or any other list of labels, by versioned questions
chained in a declarative workflow.

Work in progress. The design is in `DECISIONS.md` and `docs/contract.md`.

The companion package [sdg-tech-tagger-rs](https://github.com/KnuxV/sdg-tech-tagger-rs)
tags the same labels by published keyword queries.
